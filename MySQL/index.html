Debian/Ubuntu上安装MySQL

官方说明文档： https://dev.mysql.com/doc/refman/8.4/en/linux-installation-apt-repo.html#apt-repo-setup

需要注意：直接apt install安装会提示

Package mysql-server is not available, but is referred to by another package.
This may mean that the package is missing, has been obsoleted, or
is only available from another source
However the following packages replace it:
  mariadb-server

E: Package 'mysql-server' has no installation candidate

是因为在 Debian/Ubuntu 等系统的默认软件源中，mysql-server 包已经被 mariadb-server 所替代。

所以需要按照官方文档顺序先安装deb文件，然后更新apt，再使用apt安装。

1.下载发布包。先访问 https://dev.mysql.com/downloads/repo/apt/ 点击Download,点击No thanks, just start my download.或者复制下载链接，使用

curl -O https://dev.mysql.com/get/mysql-apt-config_0.8.40-1_all.deb<下载链接>

2.安装发布包，w.x.y-z对应版本号例如0.8.40-1。

sudo dpkg -i mysql-apt-config_w.x.y-z_all.deb

3.安装过程中会弹出要求选择服务器和其他组件版本，不确定选第一个页面ok，可以随时更改。

4.更新apt。

sudo apt-get update

5.使用APT安装MySQL

sudo apt-get install mysql-server

安装过程中，你需要输入密码 你MySQL安装的根用户。

安装完成自动启动MySQL服务

查看MySQL服务状态

systemctl status mysql

启动停止MySQL服务都使用标准systemctl命令

MySQL基本命令

1.登录MySQL数据库。启动服务后，通过以下命令来连接到Mysql服务器，密码不显示。

sudo mysql -u root -p
Enter password:*******

2.查看数据库。

mysql> show databases;
+--------------------+
| Database           |
+--------------------+
| information_schema |
| mysql              |
| performance_schema |
| sys                |
+--------------------+

3.创建数据库，IF NOT EXISTS参数表示如果数据库不存在才执行操作。

create DATABASE [IF NOT EXISTS] 数据库名称;

4.删除数据库，IF EXISTS参数表示如果数据库存在才执行操作。

drop DATABASE [IF EXISTS] 数据库名称;

5.选择数据库。

use 数据库名称;

6.创建数据表，table_name表名，column列名，datatype数据类型。

CREATE TABLE table_name (
    column1 datatype,
    column2 datatype,
    ...
);

7.删除数据表。

DROP TABLE [IF EXISTS] table_name;  -- 会检查是否存在，如果存在则删除

8.插入数据，table_name表名，column列名，value数值

INSERT INTO table_name (column1, column2, column3, ...)
VALUES (value1, value2, value3, ...);

MySQL查询语句

1.MySQL查询数据

SELECT column1, column2, ...
FROM table_name
[WHERE condition]
[ORDER BY column_name [ASC | DESC]]
[LIMIT number];

WHERE condition 是一个可选的子句，用于指定过滤条件，只返回符合条件的行。

ORDER BY column_name [ASC | DESC] 是一个可选的子句，用于指定结果集的排序顺序，默认是升序（ASC）。

LIMIT number 是一个可选的子句，用于限制返回的行数。

2.where子句

SELECT column1, column2, ...
FROM table_name
WHERE condition;

可以指定多个表，表之间用，分割

可以用AND或OR指定一个或多个条件

可以用>,<,=,!=等操作符

like模糊匹配

还有IN,NOT,BETWEEN,IS NULL,IS NOT NULL等条件

MySQL的where子句的字符串默认不区分大小写。可以用BINARY关键字来设定 WHERE 子句的字符串比较是区分大小写。如：

SELECT * from runoob_tbl WHERE BINARY runoob_author='RUNOOB.COM';
